# Brua from the command line and from CI

- [`cli/`](cli/README.md): `@meginhufr/brua-cli`, Brua from the command line: push images and animations into change sets for review, pull the released asset ids into your code, and read what the current release serves. `npx @meginhufr/brua-cli --help`.
- [`action/`](action/README.md): the GitHub Actions `Meginhufr/brua-cli/action/push` and `Meginhufr/brua-cli/action/pull`, which run the same code from a workflow.

Both are released together, under the same tag. Brua is at [brua.dev](https://brua.dev).
